# Deliverables from the ECI Round 2 live session (Oct 12, 2026)

Everything the Claude agent fleet built around this assessment, kept next to the code it describes.
Each folder is a static, self-contained snapshot; open its `index.html`. Live, hosted versions are served
through the LHI workspace portal.

| Folder | What it is |
|---|---|
| `bug-report/` | One section per fixed bug: simple view, then detail with diff, evidence, thought process. |
| `ui-walkthrough/` | 18-step Next/Back tutorial of the 16 bugs with spotlighted screenshots of the real UI. |
| `master-and-live-diagram/` | The fleet's master page (progress bars, plan, decisions), model-usage page, and a live interactive diagram of this codebase. |
| `staffing-tree/` | Which agent (ward) owned which work. |
| `storefront-app-hosted-build/` | The static build of the fixed storefront as hosted, plus its landing page. |

Snapshots exclude internal provenance files and logo videos. Session and agent links point at the author's internal
tooling and require authentication; they will not open for other viewers.

Also at the repo root: `FINDINGS.md` (all 16 bugs, commits and how to verify).
